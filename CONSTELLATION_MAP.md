# Structural Map

## Origin Layer (Precursor Repos)
- MDL Residue Test
- Early structural benchmarks
- First-instance provenance systems

These repos contain immutable origin geometry and cannot be structurally challenged.

## Stabiliser Layer (Cloudburner17)
- Admission Gate
- Burn Gate
- Timestamp Gate
- Synthetic topology
- Lifecycle harness

This layer stabilises all lifecycle-bearing systems.

## Dependent Layer (Business, Public, Invariant Core)
- Business leg repos
- Public leg repos
- Invariant-core modules

These repos route lifecycle events through Cloudburner17.

## Flow
origin → stabiliser → dependent  
Provenance flows upward; invariance flows downward.
