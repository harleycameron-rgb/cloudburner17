# Binary placeholders

The files in `binaries/` are text placeholders reserved for future compiled
tools. They are not executable binaries.

Each placeholder targets the v0.3.1 ignition schema: zero-state convergence,
topology continuity, observation, torsion commitment, and runtime diagnostics.

1. `scandoc-core.bin` — reserved for a core invariant-engine scanner for
   curvature, residue, torsion, and massless-state contracts.
2. `scandoc-cli.bin` — reserved for a command-line interface for cycle-level
   invariant verification.
3. `scandoc-ampoule.bin` — reserved for conversational-state geometric
   encoding.
4. `scandoc-microtexture.bin` — reserved for curvature drift, residue, and
   false-invariant analysis.
5. `scandoc-latent.bin` — reserved for massless convergent-state checks.
